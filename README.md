# Lab-Exercise-6


# UX Design Assignment

## Aim

To understand and apply UX design methods including solution ideation, user stories, scenarios, flow diagrams, and information architecture.

---

## 1. Solution Ideation

### Problem

Users find it difficult to book doctor appointments using a hospital mobile application.

### Ideas Generated

1. Doctor search option
2. Specialization filter
3. Available time slots
4. Online appointment booking
5. Video consultation
6. Appointment reminders
7. Cancel and reschedule option
8. Favourite doctors list

### Low-Fidelity Solution

The application includes a simple search feature, doctor selection, date and time selection, and appointment confirmation.

---

## 2. User Stories

### Persona

Name: Ravi
Age: 30
Goal: Book a doctor appointment easily.

### User Stories

1. As a patient, I want to search for doctors, so that I can find the correct specialist.

2. As a patient, I want to view available time slots, so that I can choose a convenient time.

3. As a patient, I want to book appointments online, so that I can save time.

4. As a patient, I want appointment reminders, so that I do not miss my consultation.

5. As a patient, I want to cancel or reschedule appointments, so that I can manage my schedule.

---

## 3. User Scenario

Ravi is working in his office and experiences back pain. He opens the hospital application during his lunch break. He searches for an orthopedic doctor and checks available appointment times.

He selects a suitable time slot and confirms the appointment. After receiving the confirmation notification, Ravi feels relieved.

### Environment

* Location: Office
* Device: Smartphone
* Emotion: Worried to relieved
* Task: Book a doctor appointment
